# Parameter space version 3

Version 3 is version 2 ([v2.md](v2.md)) plus four settings for the contested-yield rules. Every version 2 parameter,
derived key, constraint (C-01 to C-12) and held-fixed entry is carried over unchanged, and versions 1 and 2 stay served
exactly as before, so existing experiments, campaigns and fidelity checks replay as they ran.

The search sets the new rules only through overrides of the parameters below, validated against this record like every
other parameter. The designer form sets `game.rules.rewrite-latest-round` and
`game.rules.scoring.score-deltas.SECRET_OUTCOME_MISSED` as numbers and each of the two switches with a `false` or `true`
control. The configuration is `parameter-spaces/v3.json`.

## Added parameters

| Key | Type | Services | Baseline | Range | Step | Rationale |
|---|---|---|---|---|---|---|
| `game.rules.rewrite-latest-round` | NUMBER | game-service | 2 | [1, 3] | 1 | The last round of an era in which Rewrite may be played; a later play is rejected. A narrower window makes the commitment earlier |
| `game.rules.scoring.score-deltas.SECRET_OUTCOME_MISSED` | NUMBER | game-service | -1 | [-3, 0] | 1 | The score change of a Rewrite whose preferred outcome does not win; 0 turns the penalty off |
| `game.rules.scoring.expose-requires-declared-event` | BOOLEAN | game-service | `true` | `false`, `true` | | Whether Expose needs the target to have declared on the event |
| `game.rules.scoring.annihilation-requires-consequence` | BOOLEAN | game-service | `true` | `false`, `true` | | Whether an Annihilate scores only when it has a consequence |

No added value appears in an objective or threshold constraint, so version 3 adds no constraint. `REWRITE` in the
once-per-era budgeted set stays served configuration and is not a parameter.

A baseline rules document must carry all four keys at their baseline values for version 3 to apply to it. At startup the
workbench logs a warning that names the `rules-document` setting of each declared baseline that lacks them; new
campaigns and designer variants use the newest version, so such a baseline is refused when first used.
