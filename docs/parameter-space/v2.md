# Parameter space, version 2

Parameter space version 2 (`parameter-spaces/v2.json`) is version 1 ([v1.md](v1.md)) with the faction-bet window and a
Thread shift that may be zero. New campaigns and the designer form use it; version 1 stays served unchanged, so a
campaign stored on it replays exactly. The rationale of every other parameter, range and constraint is the one recorded
for version 1.

## Changed from version 1

| Key | Type | Services | Baseline | Range | Step | Rationale |
|---|---|---|---|---|---|---|
| `game.rules.faction-bet-latest-round` | NUMBER | game-service, timeline-service | 2 | [1, 3] | 1 | The latest round of the one window for every faction bet; it replaces `game.rules.rewrite-latest-round`, which this version no longer lists |
| `game.rules.probability.thread-shift` | NUMBER | timeline-service | 0 | [0, 15] | 5 | The Thread shift; 0 is a Thread without push (version 1: baseline 10, range [5, 15]) |
| `game.rules.victory.final-era-objective-discount` | NUMBER | game-service | 0 | [0, 2] | 1 | Baseline 0 is no final-era discount (version 1: baseline 1) |
| `game.rules.victory.eraser-annihilations-by-player-count.5` | NUMBER | game-service | 4 | [3, 5] | 1 | Baseline equal to `eraser-annihilations`: no five-player exception (version 1: baseline 3) |
| `game.rules.victory.activist-consecutive-eras-by-player-count.5` | BOOLEAN | game-service | `true` | `false`, `true` | | Baseline `true`: the five-player Activist streak is consecutive like the other table sizes (version 1: baseline `false`) |

`game.rules.victory.weaver-chain-length` keeps its range [3, 4] and its baseline 4. Every constraint of version 1 holds
at the new baselines and is unchanged.

A variant on version 2 that overrides `game.rules.rewrite-latest-round` is refused naming that key, and so is a
`game.rules.probability.thread-shift` below 0.
