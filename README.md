## Delivery backlog

System-wide coordination stays in the infrastructure epic for the simulation and balance workbench. The
workbench delivers seven packages, in implementation order:

1. Experiment freezing and matrix preview — attributable experiments and the exact case matrix.
2. Versioned baseline policies — explicit baseline strategies without privileged information.
3. Durable real-service batches — launch, cancel and resume without losing completed work.
4. Evidence retention and saved-case reproduction — per-case evidence plus clean-lane reproduction.
5. Balance comparisons — attributable populations, honest uncertainty, and versioned exports.
6. Designer UI and replay inspector — the full research workflow without hand-operated endpoints.
7. Application workflow proof — integrated proof with ordinary gameplay regressions green.

The live backlog (issue tracking and board status) lives in this repository's issues and the
organization board; this file describes product scope only.
